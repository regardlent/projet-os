5. Invariants NON-NÉGOCIABLES (à préserver)

  • GPU : allowCpuFallback=false, requireGpu=true, requireFlashReady=true pour les gates concernés ; GPU_OFFLOAD_PROOF doit être une preuve réelle (delta VRAM + backend + smoke) ; jamais de qualification/PASS/benchmark simulé.
  • Process : jamais de kill auto de process utilisateur, jamais de reset Docker, jamais de restart Windows ; seule la protection IDE (Antigravity) avec conditions validées.
  • LocalAI : loopback canonique 127.0.0.1:8080/v1 ; pas de fallback cloud caché.
  • Security : trust_remote_code=false ; SHA/empreintes vérifiées ; pas de secret dans les logs ; protéger .env/clés/.git/config ; pas de path traversal ; pas d'écriture hors workspace ; delete/rename interdits par défaut ; pas d'élévation destructive.
  • Honesty : états autorisés PASS / PASS_WITH_WARNINGS / WARN / BLOCKED / FAIL / NOT_TESTED / NOT_APPLICABLE ; interdits : « probablement PASS », « devrait fonctionner », « semble validé ».
