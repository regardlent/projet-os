9. Autonomie (write-lane gated)

L'agent autonome travaille dans un cadre borné et approuvé.

  1. /autonomy plan → buildAutonomyPlan (budget minutes par complexité + checkpoints + deadline).
  2. buildWritePlan + buildWriteScope → plan de write-lane : opérations autorisées (create/modify/patch), maxFiles, maxBytesChanged, maxPatchLines, delete/rename bloqués par défaut, expiresAt.
  3. guardWritePath → refuse hors workspace (transversal), fichiers protégés (.git/config, node_modules), secrets (.env, clés).
  4. Approbation explicite avant toute mutation (jamais d'écriture aveugle).
  5. Boucle : activitée journalisée + summary + handoff.
  6. AutonomyModelSelector : choisit le modèle selon la complexité.
  7. AutonomyActivityLedger : suivi minute par minute (détecte le dépassement de budget).

10. Endurance GPU Ladder

Validation de création de projet obligatoire sur GPU (pas de fallback CPU). EnduranceLadder (machine à états pure, séquence 5→10→20→30→60 sans skip).

  • Gate dur : le timer ne démarre que si GPU_OFFLOAD_PROOF = PASS (GPU détecté + NVIDIA + backend LocalAI GPU + VRAM libre + modèle éligible + sécurité + ≤4B + FLASH_READY). Sinon BLOCKED_GPU.
  • Reset-on-failure : échec/bug/OOM → temps accumulé perdu, reprise à 00:00 sur le même palier (attempt++).
  • Modules : EnduranceLedger (bug + GPU entries), EnduranceReset (reset-from-zero + isolation), ProjectCreationEvidence (model record + evidence pack), EnduranceFailover (failover dédié), GpuBenchmark (TTFT/tokens·s/VRAM/stability), FleetQualifier (qualification flotte), EnduranceRouter, EnduranceLab (API produit unique), GpuQualificationQueue.
  • Policy : requireGpu=true, requireFlashReady=true, allowCpuFallback=false. Jamais de PASS simulé ni de kill de process.
  • Preuve offload : delta VRAM (nvidia-smi avant/après) + /backend/monitor?model= + smoke inference. GpuBenchmark : 1 warmup + ≥3 mesures.

Résultat final : ladder 5/5 passée (5·10·20·30·60 min) → PROJECT_CREATION_ENDURANCE_READY = PASS.
